# Implementation stages

1. Commit this specification, implementation plan, and task list before the
   implementation branch. Open a specification pull request.
2. Apply the Tkinter restyling and preserve the original desktop workflow.
3. Build the local browser converter using the shared core. Verify the responsive
   layout and revise the English README and report.
4. Add Selenium tests for conversion, keyboard submission, date changes, fallback,
   offline recovery after restart, and unavailable or damaged caches. Document
   the test dependencies and run the unit and browser suites.
