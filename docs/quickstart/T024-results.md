# T024: проход по quickstart.md

**Кто выполнил:** Claude Code (не Antigravity). С прогона 2 агент Antigravity работал в режиме
только правки файлов и не мог запускать программу.

**Как:** настоящее окно `ConverterApp` с настоящим `RateService` и живым источником bnm.md.
Действия пользователя выполнял скрипт: ввод в поля, выбор в списках, нажатия кнопок,
`root.update()`. Офлайн задавался переменными окружения из quickstart: недоступный адрес
`CURRENCY_CONVERTER_SOURCE_URL=http://127.0.0.1:9/` и отдельный `CURRENCY_CONVERTER_HOME`.
Дата прохода: 19.11.2026.

**Замечание (недочёт спецификации, не агента):** в сообщении о недоступности источника
показывается технический текст исключения, например
`<urlopen error [WinError 10061] No connection could be made…>`. Так буквально требует контракт:
`SourceUnavailableError` с сообщением `"Нет связи с bnm.md: {detail}"`. Конституция при этом
просит «понятное сообщение». Агент реализовал контракт точно; противоречие заложено в
спецификации.
